# Вибори під конвоєм – 2

Порівняльна інфографіка «Новини Донбасу»: чи посилює Росія репресії на тимчасово окупованих територіях України під час виборів. 16 виборчих подій з 2014 р., 34 вікна порівняння, 785 інцидентів і 637 метрик з першоджерелами. Станом на 04.10.2026.

Імена постраждалих подано ініціалами.
